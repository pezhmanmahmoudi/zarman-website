# Redesign Notes

## Updated direction
Zarman should be redesigned as a premium, trustworthy, modern fintech website with a clear product structure and strong design discipline.

The redesign should not focus on creating more dramatic visual sections.
It should focus on:
- better structure
- better hierarchy
- better trust design
- better content
- stronger consistency
- smoother experience
- more practical product communication

---

## Core decisions
- The current pilot-style sections under Services should be removed from the public homepage.
- Selected visual or content elements from those sections may be reused later.
- The navigation must become active and fully integrated.
- A rate-history chart for AUD to IRR should be added beside the calculator.
- Font weights should be reduced and typography should become more refined.
- The hero should be enriched with useful support elements instead of remaining visually empty.
- Responsiveness needs a full systematic pass.
- SEO must be improved through structure, content, semantics, and navigation.

---

## Typography direction
- Reduce excessive boldness
- Use bold only for important hierarchy
- Build a proper type scale
- Keep Persian text readable and calm
- Make body text lighter and more refined

Recommended direction:
- Hero heading: 700
- Section headings: 600 or 700
- Body text: 400 or 500
- Button text: 500 or 600
- Labels / captions: 500

---

## Hero redesign direction
The hero should remain premium and dark, but it should no longer feel visually empty.

Possible support elements:
- trust pills
- small utility chips
- subtle supporting UI markers
- clearer CTA grouping

The hero should answer quickly:
- what Zarman is
- who it is for
- why it is trustworthy
- what the next step is

---

## Calculator section direction
The calculator should become a key utility section, not just a floating card.

The new layout should include:
- calculator
- rate history chart
- short contextual explanation
- better desktop composition
- better balance of empty and filled space

The chart should be:
- simple
- elegant
- readable
- trustworthy
- not overly “trading platform” in style

---

## Content direction
Website copy needs to be rewritten in a more mature fintech tone:
- clearer
- calmer
- more trustworthy
- less decorative
- more product-focused

Needed content areas:
- Hero copy
- About copy
- How it works
- Services
- Why Zarman
- Security section
- FAQ
- Final CTA

---

## Motion direction
- reduce inconsistency
- unify reveal patterns
- reduce unnecessary heavy effects
- prioritize smoothness over novelty
- avoid section-specific animation personalities

---

## Responsive direction
The redesign must include a full responsive pass for:
- mobile
- tablet
- laptop
- large desktop

Specific focus:
- vertical rhythm
- text line length
- component spacing
- visual/text balance
- section height control

---

## SEO direction
The redesign must improve:
- heading structure
- semantic hierarchy
- navigation crawlability
- content clarity
- FAQ value
- page purpose definition

SEO improvement should come from:
- better structure
- better text
- better semantics
- better page hierarchy

---

## Final design principle
The redesign should aim for:
“controlled premium fintech product experience”

Not:
- more visual complexity
- more showcase sections
- more decorative motion

The question for every section should be:
- what is the job of this section?
- what should the user understand here?
- what should the user feel here?
- does this improve trust, clarity, or conversion?
